# Security policy

Until FoxLift 1.0, the current `main` branch and the latest published release receive security
fixes. Older releases are unsupported.

## Report a vulnerability

Use **Security → Report a vulnerability** in the GitHub repository. Do not open a public issue.

Include the affected version, impact, reproduction steps, and the smallest safe reproducer. Do
not send proprietary or confidential files, credentials, licensed VFP media, ReFox output, or
ReFox-derived material. Submit only inputs you own or are authorized to inspect and redistribute.
If the issue depends on restricted material, describe its structure first and wait for secure
coordination before sharing anything.

Parser crashes, path traversal, unsafe generated paths, code execution, release compromise, and
dependency vulnerabilities belong in a private report. Ordinary decompilation inaccuracies may
be reported with the public bug form.
